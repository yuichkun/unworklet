unworklet DevTools prototype

This is a throwaway sandbox. The app itself is intentionally minimal — the real surface to inspect is the Vite DevTools floating icon that should appear at the bottom of the viewport (or the bottom-right corner) once vp dev is running.

idle — click start to run the RC-20 supply nodes
What to look for
  • An indicator badge on the floating Vite icon (driven by ctx.messages.add({ ..., notify: true })).
  • A toast popping up briefly when the page loads.
  • Click the floating icon → a single unworklet dock entry. Opening it loads a Vue SPA iframe with a sidebar switching between 4 views: Audio graph / Live state / Signals / MIDI.
  • Open the Command Palette inside DevTools and look for unworklet:* entries.
